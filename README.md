# TFG-en-CSC

Este repositorio contiene los códigos y scripts de simulación desarrollados para el Trabajo Fin de Grado en Física titulado **"Análisis de un modelo estocástico de células madre cancerígenas"**, realizado en la **Facultad de Ciencias de la Universidad de Córdoba**.

El objetivo principal del proyecto es modelar y analizar la dinámica poblacional de un tumor formado por células madre cancerígenas (CSC) y células diferenciadas, estudiando el impacto de las fluctuaciones estocásticas y la eficacia de diferentes estrategias terapéuticas (tratamientos continuos vs. cíclicos).
